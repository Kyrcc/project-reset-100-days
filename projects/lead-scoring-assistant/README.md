# 销售线索评分器（Lead Scoring Assistant）

一个纯 Python 标准库实现的销售线索（Lead）自动评分工具，无需安装任何第三方依赖包，
在装有 Python 3 的普通 Windows 电脑上即可直接双击 / 命令行运行。

---

## 一、要解决的业务问题

销售团队每天会收到大量线索（潜在客户），但人力有限，不可能对每一条线索都投入同等的
跟进精力。如果单纯按"谁先进来谁先跟"的顺序处理，很容易把时间浪费在成交概率很低的
线索上，而真正高价值的线索却被延误。

本工具的目标是：**用一套透明、可解释、可复现的规则，把杂乱的线索列表转换成一份
按优先级从高到低排序的名单**，帮助销售人员把有限的时间优先投入到最值得跟进的客户上。

它不是"预测谁会成交"的机器学习模型，而是一套**基于业务经验设定的打分规则**——
每个人都能看懂分数是怎么来的，也可以根据实际业务效果随时调整规则。

---

## 二、评分规则

总分 100 分，由 5 个维度组成，**每个维度满分 20 分**：

| 维度 | 含义 | 打分依据（可在代码中调整） |
|---|---|---|
| 公司规模 company_size | 客户公司的规模分类或员工人数，规模越大通常预算和决策链越完整 | 分类：大型=20分、中型=12分、小型=5分；人数：≥201人=20分、51–200人=15分、11–50人=10分、1–10人=5分 |
| 职位 job_title | 联系人的职位越高/越接近决策层，推进成交的把握越大 | 高层（老板/董事长/总经理/总监/VP/CEO/CTO/创始人等）=20分；经理/主管=14分；专员/工程师/分析师等=8分；实习生/助理=3分；无法识别的职位=按8分处理并给出提示 |
| 预算 budget | 客户预算等级或具体采购预算金额 | 分类：高=20分、中=12分、低=5分、无=0分；金额：≥100,000=20分、50,000–99,999=15分、10,000–49,999=10分、1–9,999=5分、0=0分 |
| 紧迫度 urgency | 客户当前的采购紧迫程度，取值必须是"高/中/低/无"之一 | 高=20分；中=12分；低=5分；无=0分 |
| 互动程度 engagement | 客户互动等级或累计互动次数（如打开邮件、参加演示、访问官网等） | 分类：高=20分、中=12分、低=5分、无=0分；次数：≥10次=20分、5–9次=14分、1–4次=8分、0次=0分 |

**总分 = 5 项之和（0–100分）**

### 等级划分
- **A 级**：总分 ≥ 80 分 —— 优先跟进
- **B 级**：60 ≤ 总分 < 80 分 —— 常规跟进
- **C 级**：总分 < 60 分 —— 低优先级 / 培育阶段

最终结果按总分从高到低排序，方便销售团队按顺序处理。

## 三、运行方法

### 环境要求
- 已安装 Python 3（3.6 及以上均可）
- **不需要安装任何第三方库**（未使用 pandas、numpy 等），代码只用了 Python 自带的
  `csv`、`sys`、`os` 模块，普通 Windows 电脑装好 Python 后即可直接运行。

### 步骤
1. 把 `lead_scoring.py`、`leads_sample.csv` 放在同一个文件夹中。
2. 打开命令提示符（cmd）或 PowerShell，`cd` 进入该文件夹。
3. 运行：

   ```bash
   python lead_scoring.py
   ```

   默认会读取同目录下的 `leads_sample.csv`，并生成 `leads_scored.csv`。

4. 如果想使用自己的数据文件，也可以指定输入/输出文件名：

   ```bash
   python lead_scoring.py 我的线索.csv 打分结果.csv
   ```

### 输入文件格式（CSV，必须包含以下 7 列）

```
lead_id,company_name,company_size,job_title,budget,urgency,engagement
```

- `company_size`：「大型」「中型」「小型」，或正整数（员工人数）
- `job_title`：文本（职位名称，中英文均可）
- `budget`：「高」「中」「低」「无」，或数字（预算金额）
- `urgency`：必须是「高」「中」「低」「无」四选一
- `engagement`：「高」「中」「低」「无」，或非负整数（互动次数）

### 输出文件

`leads_scored.csv`，包含每个维度的得分、总分、等级，并已按总分从高到低排序。

### 错误提示

如果某一行数据存在无效字段（例如公司规模为空、预算填了文字、紧迫度不是规定的
四个取值之一），程序会：
1. 在命令行中打印**中文提示**，说明是第几行、哪个字段、为什么无效；
2. 跳过这一行，不中断整体运行，继续处理其余数据；
3. 最终在汇总信息中报告总共跳过了多少条无效线索。

职位字段比较特殊：如果职位文本无法匹配任何已知的职级关键词，程序不会将其视为
"无效数据"而跳过，而是给予默认分数（8分）并打印提示，因为职位名称的写法五花八门，
过于严格反而会丢弃大量本可以打分的正常线索。

## 四、证据边界（重要：请务必了解本工具的局限性）

1. **这是规则打分，不是预测模型**。分数反映的是"符合我们设定的经验规则的程度"，
   不代表真实成交概率，也没有经过历史成交数据的验证/回归。如果要用于严肃的
   销售预测决策，建议先用历史成交数据核对这套规则的准确性，并据此调整分数阈值。

2. **规则本身依赖人工设定的阈值和权重**，例如"5个维度权重相等"、"预算10万以上封顶"
   等，都是示例性质的假设，未必适合所有行业/产品/客单价。使用前应结合实际业务
   （客单价、销售周期、历史转化率等）调整代码中 `score_*` 函数里的分段阈值。

3. **职位打分依赖关键词匹配**，无法理解职位的真实语境（例如"总监助理"可能会被
   误判为高分职位），建议在关键词列表命中率不高时人工复核 B/A 级线索的职位字段。

4. **数据质量决定结果质量**。如果输入数据本身有偏差（例如互动次数统计口径不一致、
   预算数字是销售随口估的），打出来的分数也只会反映这些偏差，工具本身无法核实
   数据的真实性。

5. **本工具不做任何网络请求、不访问外部数据源**，只处理你提供的本地 CSV 文件，
   所有计算逻辑都在 `lead_scoring.py` 中公开可见、可审查、可修改。
