# 企业微信称呼助手

这个工具只做一件事：读取当前聊天窗口左上角的客户姓名，生成称呼，并把“称呼＋今日话术”填入聊天框。它不会自动发送消息。

## 使用方法

第一次测试时，请先使用不会操作聊天框的诊断模式：

1. 双击 `诊断称呼识别.cmd`。
2. 打开一个测试客户聊天窗口。
3. 按 `F8`。
4. 检查弹窗中的“识别文字、客户姓名、生成称呼”是否正确。
5. 关闭诊断程序，再按下面步骤使用正式模式。

正式模式：

1. 打开 `今日话术.txt`，填写当天固定话术。建议以逗号或其他标点开头。
2. 双击 `启动称呼助手.cmd`。看到绿色的“企业微信称呼助手正在运行”后即可使用；可以将这个窗口最小化，但不要关闭。
3. 打开一个客户聊天窗口，确保左上角能看到类似 `甘小圆_56396799_西安` 的标题。
4. 按 `F8`。
5. 检查聊天框中的姓名和话术，确认无误后手动发送。

关闭工具时，可以直接关闭“企业微信称呼助手”窗口；也可以右键单击任务栏右下角的助手图标，选择“退出称呼助手”。

## 当前称呼规则

- 普通三字姓名：取后两个字，例如 `甘小圆` → `小圆`。
- 普通两字姓名：取姓氏并加“哥”，例如 `张三` → `张哥`。
- 常见复姓姓名：取复姓，例如 `欧阳成` → `欧阳`。
- 四字及以上普通姓名：默认取最后两个字。

## 安全设计

- 诊断模式不会点击输入框、复制内容或填入话术。
- 工具不会按回车，也不会点击发送。
- 每条消息都保留人工检查步骤。
- 识别失败时不会填入消息，会在右下角显示错误提示。

## 注意事项

- 按 F8 前，客户聊天窗口必须是当前正在操作的窗口。
- 客户标题中应包含姓名和数字编号；工具利用数字编号确定姓名的结束位置。
- 如果聊天窗口布局与示例截图差异很大，可能需要调整标题截图区域或输入框位置。
- 当前版本同时支持小型独立聊天窗口，以及 2560 像素宽屏主窗口布局。
- 第一次正式使用时，请先用测试客户验证，不要直接对真实客户发送。
