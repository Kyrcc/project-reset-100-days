## 业务问题

销售人员每天需要重复执行以下操作：

1. 查看客户姓名；
2. 按团队习惯生成合适的称呼；
3. 拼接当天的固定跟进话术；
4. 将内容填入企业微信聊天框；
5. 检查后发送。

手工处理不仅重复，还容易出现称呼复制错误、漏改姓名或误发送等问题。

## 自动化方案

用户打开客户聊天窗口后按下 `F8`，助手会：

1. 截取当前聊天窗口的标题区域；
2. 调用 Windows 内置 OCR 识别文字；
3. 从标题中提取客户姓名；
4. 根据姓名长度和复姓规则生成称呼；
5. 读取 `今日话术.txt`；
6. 将“称呼＋话术”填入聊天框；
7. 停在发送前，等待人工检查。

## 人机协作设计

这是一个“自动执行＋人工确认”的销售辅助流程：

- 自动化负责识别、拼接和填入；
- 销售人员负责核对语气、客户身份和发送时机；
- 程序不会按回车，也不会点击发送；
- 识别失败时不填入消息，并显示错误提示。

这种设计避免把高风险的客户沟通完全交给自动化。
