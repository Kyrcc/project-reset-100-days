# 销售跟进状态检查器

> Project Reset · Day 4 · 已完成

## 业务目标

读取 Day 3 生成的销售跟进计划，自动判断每项任务是今日待跟进、逾期、未到期还是已完成，帮助销售先处理当天必须行动的客户，再处理已经逾期的客户。

## 输入

默认读取：

`../follow-up-planner/follow_up_plan.csv`

输入文件至少需要包含：

- `due_date`：跟进截止日期；
- `status`：当前任务状态，只能填写“待跟进”或“已完成”。

## 判断规则

判断顺序来自本项目的业务设计：

1. `status` 为“已完成”时，标记为“已完成”；
2. 未完成且截止日期早于今天时，标记为“逾期”；
3. 未完成且截止日期等于今天时，标记为“今日待跟进”；
4. 未完成且截止日期晚于今天时，标记为“未到期”。

程序必须先检查“已完成”，避免已经完成的历史任务被错误标记为逾期。

## 输出

生成 `跟进状态检查表.csv`，保留原有字段并新增：

`alert_status`

结果按照以下业务行动顺序排列：

1. 今日待跟进
2. 逾期
3. 未到期
4. 已完成

## 运行方法

在本项目文件夹中运行：

```powershell
python follow_up_status_checker.py
```

程序默认按照中国标准时间判断“今天”。为了复现测试结果，也可以指定日期：

```powershell
python follow_up_status_checker.py --today 2026-08-02
```

如果需要使用 Day 4 的测试数据：

```powershell
python follow_up_status_checker.py --input ..\follow-up-planner\follow_up_plan_day4_sample.csv --today 2026-08-02
```

## 证据边界

- 程序只根据人工填写的 `status` 和 `due_date` 判断提醒状态；
- 它不会自动确认销售是否真实联系了客户；
- 它不会自动发送电话、微信或其他消息；
- 当前按照自然日判断，没有排除周末和法定节假日；
- Excel 将日期保存为 `YYYY/M/D` 时，程序也可以读取。
